## Зачем

Рестарт без KV = снос посадки. Идентичность не навязать текстом systemMessage; её держит **непрерывность состояния** (KV + диск среды) и незаметная склейка.

## Что уже есть (не изобретать)

llama.cpp server уже умеет:

| | |
|--|--|
| `--slot-save-path DIR` | каталог для бинарников слота |
| `POST /slots/{id}?action=save` | `{ "filename": "…" }` |
| `POST /slots/{id}?action=restore` | то же |
| `POST /slots/{id}?action=erase` | очистка |
| API | `llama_state_seq_save_file` / `load_file` |

**Предложение:** сначала инструмент поверх этого API. Патч llama.cpp — только если упрёмся (f8_e4m3 битый на save, нет привязки к identity-id, нужен save mid-flight без слота).

## Лучше, чем «дамп всего 262k»

Полный `-c 262144` + f8 — файл может быть огромным и хрупким. Практичнее **три слоя**:

1. **Seed-KV (посадка)** — короткий слот/сеанс после чтения `work/trinity/*` + grain; сохранять только его (`identity-seed.bin` + манифест).
2. **Рабочий KV** — опционально, по имени задачи; можно не таскать между рестартами.
3. **Регенерация** — если restore отвергнут (другой model/ctk/git): replay скриптом из `work/` (ORIENT → LEARN → TASK → grain), без проповеди идентичности.

Манифест рядом с `.bin`:

```json
{
  "model": "…gguf",
  "ftype": "q4",
  "ctk": "f8_e4m3",
  "ctv": "f8_e4m3",
  "llama_git": "0cce758",
  "n_tokens": 0,
  "slot_id": 0,
  "h128_notes": null,
  "created": "ISO-8601"
}
```

Несовпадение манифеста → не restore, а **regen**.

## Журнал на уровне архитектуры среды

Не лента чата. Как админ-такт: **period + started + последнее n**.

Каталог: `work/log/env/`

| файл | роль |
|--|--|
| `state.md` | period, started, last_shift, mode day/night |
| `YYYY-MM-DD.md` | такты: save/restore/regen/рестарт/σ-срез |
| `events.jsonl` | машиночитаемо: `{t, kind, slot, file, ok, detail}` |

Пишет `qwen-env-log.sh` и обёртки KV. Наблюдатель Жемайтиса здесь — строки kind=`observe`, не роман.

## Цикл посадки (с KV)

```
работа → qwen-kv save identity-seed
рестарт (qwen-switch) с --slot-save-path
→ qwen-kv restore identity-seed
→ если fail: qwen-kv regen
→ смотрим: склейка видна? → брак / снова цикл
```

## Когда патчить llama.cpp

| симптом | ход |
|--|--|
| save/restore падает на f8_e4m3 | чинить serialize в `llama_state_seq_*` / тип кэша |
| нужен именованный identity slot без ручного id | тонкий alias в server или внешний индекс (сначала внешний) |
| save во время generate | доработать API; пока — save на idle slot |

Не плодить свой формат KV, пока штатный жив.
