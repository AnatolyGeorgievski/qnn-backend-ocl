> Снимок конфигов эталонного контура llama-server + Qwen3.8-27B для разработки QNN Backend-OCL / quant. Не зерно QuantumNN.

## Контур

| | |
|--|--|
| хост | arc3 (`192.168.1.187`) |
| GPU | RTX PRO 4000 Blackwell (CUDA); OCL/IR — цель проекта, не текущий runtime Qwen |
| бинарь | `$ROOT/build/bin/llama-server` · `ROOT=/home/george/src/llama.cpp` |
| порт | `18081` · `HOST=0.0.0.0` |
| контекст | `-c 262144` |
| offload | `-ngl 99` · `-sm layer` · `-ts 50,50` |
| KV | `-ctk f8_e4m3 -ctv f8_e4m3` |
| sampling | `--temp 0` · `--reasoning off` |
| UI/tools | webui · tools read/write/grep/glob/get_info · MCP fetch only |

## Профили

| профиль | модель | alias |
|--|--|--|
| q4 (default `qwen-server.env`) | `Qwen3.8-27B-Q4_K_M.gguf` | `qwen3.8-27b-q4` |
| q8 | `Qwen3.8-27B-Q8_0.gguf` | `qwen3.8-27b-q8` |

Переключение: `qwen-switch.sh q4|q8` → копирует env в `qwen-server.env` → `qwen-server-start.sh`.

## Песочница (ui-config)

- весь arc3 — writable sandbox
- соседей LAN нет (нет shell/netd; fetch без private IPs)
- интернет читать можно; публиковать нельзя
- cwd default `/home/george/work`
- `temperature: 0` в UI

## MCP

Только `fetch` (`mcp-server-fetch --ignore-robots-txt`). Без `--allow-private-ips`. netd в MCP не подключён.


## Сборка llama.cpp (arc3)

| | |
|--|--|
| дерево | `/home/george/src/llama.cpp` · git `0cce758` (2026-11-14) |
| build | Ninja · `CMAKE_BUILD_TYPE=Release` · `BUILD_SHARED_LIBS=ON` |
| CUDA | toolkit **13.2** · `nvcc` `/usr/local/cuda-13.2/bin/nvcc` |
| arch | `CMAKE_CUDA_ARCHITECTURES=120a` (Blackwell / sm_120a) |
| GPU/driver | RTX PRO 4000 Blackwell · driver `595.99.02` · compute 12.0 |
| backends | `GGML_CUDA=ON` · CPU+CUDA (`GGML_OPENCL=OFF` · `GGML_RPC=OFF`) |
| FA | `GGML_CUDA_FA=ON` · quants включают `f8_e4m3-f8_e4m3` |
| прочее CUDA | `GRAPHS=ON` · `NCCL=ON` · `COMPRESSION_MODE=size` |
| llama | `LLAMA_BUILD_SERVER=ON` · TOOLS/UI · `LLAMA_OPENSSL=ON` |

Воспроизведение: `log/qwen/llama-cpp-cmake.sh` · плоский снимок флагов: `log/qwen/llama-cpp-build.env`.
