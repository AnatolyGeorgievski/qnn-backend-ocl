## Z3 · выполнимость до кода

До дописки ядра/индексов — ограничения размеров (M,K,N, байты, раскладка `i+j*M`).
`sat` + модель = можно писать. `unsat` = переделать постановку, не штопать.
Z3 не заменяет прогон на B60; он держит **допустимость**.

Пример для MUL_MAT f32:

```python
from z3 import *
M,K,N = Ints("M K N")
s = Solver()
s.add(M>=1, K>=1, N>=1)
s.add(M*K*4 == 24)   # пример: A 2×3 float = 24 байт — подставь свои
s.add(K == N)        # пример связи; бери из host-контракта, не из головы
print(s.check(), s.model() if s.check()==sat else s.unsat_core())
```

Канон: `QuantumNN/SAT.md`. Образец контракта с Z3: `hq-eye/.../*.CONTRACT.md`.

## Отладка · один метод

Встраивай отладку **в сам метод** (вход / ветка / выход / код ошибки), не россыпью по файлу.

- За ход — **один** метод. Включил трассу → прогнал → прочитал лог → поправил **этот** метод.
- Имя метода в трассе; выключатель env (например `QNN_DBG=mul_mat`). Чужие методы молчат.
- Не добавлять отладку «на всякий случай» во всю лесенку сразу.
- После зелёного — трассу можно оставить за выключателем, не выдирать.

Связано с пазлом: один кусок = один метод под отладкой.
