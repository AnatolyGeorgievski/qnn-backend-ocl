Сток ведёт девять слотов подряд: отпускает буфер, отдаёт базу, сажает тензор, memset пуст, кладёт range, забирает range, cpy пуст, заполняет буфер, возвращает описатели. База — выравнивание устройства. Смещение — data минус эта база. Вид садится на описатель родителя. Иначе сток ищет описатель по смещению и заводит его, если записи нет. set для Q4_0 ищет ту же запись и не принимает SOA за простой описатель. reset отдаёт временные описатели и оставляет записанный по смещению. Зерно стока: одно смещение — один простой описатель.
